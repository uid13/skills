# 布局配方库

> 好的布局 = 清晰的视觉层级 + 舒适的留白。本文件收录常用图像布局模式。

## 🎯 通用布局原则

### 1. 黄金分割（0.618）

```xml
<!-- 文字位于垂直 38.2% 位置（1 - 0.618），装饰元素在另一侧 -->
<text y="38.2%">主标题</text>
<decor x="61.8%" y="50%"/>
```

### 2. 三分法则

将画布按 1/3、2/3 切分，关键元素放在切分线和交点处：

```xml
<!-- 标题在横向 1/3 位置 -->
<text x="33.33%" y="50%">居中标题</text>

<!-- 三分法 4 个视觉焦点 -->
(33.33%, 33.33%)  (66.66%, 33.33%)
(33.33%, 66.66%)  (66.66%, 66.66%)
```

### 3. 安全区域

```xml
<!-- 保留 5-10% 边距，避免元素被裁切 -->
<!-- 微信公众号封面会在不同设备上显示为略微不同的比例 -->
<rect x="5%" y="5%" width="90%" height="90%" fill="none"/>
```

## 📐 常见布局模式

### Layout A: 居中对称（经典封面）

```
┌─────────────────────────┐
│                         │
│     ═══════════════     │
│                         │
│      [主标题文字]        │
│      [副标题文字]        │
│                         │
│     ═══════════════     │
│                         │
└─────────────────────────┘
```

**适合**：博客封面、PPT 首页、报告封面

**SVG 模板**：

```xml
<svg viewBox="0 0 900 383">
  <!-- 标题居中，位于垂直 40% -->
  <text x="50%" y="40%" text-anchor="middle"
        font-size="60" font-weight="700" fill="#2B2D42">
    主标题
  </text>
  
  <!-- 副标题在 60% 位置 -->
  <text x="50%" y="60%" text-anchor="middle"
        font-size="32" font-weight="400" fill="#8D99AE">
    副标题文字
  </text>
  
  <!-- 上下分隔线（可选） -->
  <line x1="35%" y1="25%" x2="65%" y2="25%" stroke="#EDF2F4" stroke-width="2"/>
  <line x1="35%" y1="75%" x2="65%" y2="75%" stroke="#EDF2F4" stroke-width="2"/>
</svg>
```

### Layout B: 左文右图（人物/产品介绍）

```
┌─────────────────────────┐
│                         │
│  主标题                │
│  副标题文字较长         │
│                         │
│  ┌──────────┐          │
│  │  图片    │          │
│  │  区域    │          │
│  └──────────┘          │
└─────────────────────────┘
```

**适合**：人物介绍、产品图、对比图

**SVG 模板**：

```xml
<svg viewBox="0 0 1200 630">
  <!-- 左侧文字（占 60%） -->
  <text x="8%" y="40%" font-size="56" font-weight="700">
    主标题
  </text>
  <text x="8%" y="60%" font-size="28" fill="#8D99AE">
    副标题文字
  </text>
  
  <!-- 右侧图片（占 35%，位于 60%-95%） -->
  <rect x="60%" y="15%" width="35%" height="70%"
        fill="url(#bg-grad)" rx="8"/>
</svg>
```

### Layout C: 顶部横幅 + 内容区（技术博客）

```
┌─────────────────────────┐
│ ═══════════════════════ │ ← 顶部彩色条
│                         │
│    [主标题]              │
│    [副标题]              │
│    [关键词标签] [标签]   │
│                         │
│   [装饰图形/Logo]        │
└─────────────────────────┘
```

**适合**：技术博客、文档首页

### Layout D: 底部信息条（Logo + 作者）

```
┌─────────────────────────┐
│                         │
│                         │
│    [大标题居中]          │
│                         │
│                         │
│─────────────────────────│
│ Logo        作者 · 日期  │
└─────────────────────────┘
```

**适合**：PPT 尾页、卡片式内容

**SVG 模板**：

```xml
<svg viewBox="0 0 900 383">
  <!-- 大标题垂直居中 -->
  <text x="50%" y="45%" text-anchor="middle"
        font-size="48">核心主题</text>
  
  <!-- 底部栏（高 15%） -->
  <rect x="0" y="85%" width="100%" height="15%" fill="#1E1E2E"/>
  
  <!-- 底部左：Logo -->
  <text x="3%" y="93%" fill="#FFF" font-size="20">
    @uid13
  </text>
  
  <!-- 底部右：日期 -->
  <text x="97%" y="93%" fill="#AAA" font-size="18" text-anchor="end">
    2026.05.28
  </text>
</svg>
```

### Layout E: 网格布局（多图展示）

```
┌────┬────┐
│ 1  │ 2  │  ← 2x2 四宫格
├────┼────┤
│ 3  │ 4  │
└────┴────┘
```

**适合**：产品对比、功能列表、Before/After

**SVG 模板**：

```xml
<svg viewBox="0 0 1080 1080">
  <!-- 2x2 网格，每格 50% 宽 50% 高，间距 2% -->
  
  <!-- 第一格 (左上) -->
  <g transform="translate(1%,1%)">
    <rect width="48%" height="48%" fill="#FFF" stroke="#DDD"/>
    <text x="24%" y="24%" text-anchor="middle">项目 1</text>
  </g>
  
  <!-- 第二格 (右上) -->
  <g transform="translate(51%,1%)">
    <rect width="48%" height="48%" fill="#FFF" stroke="#DDD"/>
    <text x="24%" y="24%" text-anchor="middle">项目 2</text>
  </g>
  
  <!-- 第三格 (左下) -->
  <g transform="translate(1%,51%)">
    <rect width="48%" height="48%" fill="#FFF" stroke="#DDD"/>
    <text x="24%" y="24%" text-anchor="middle">项目 3</text>
  </g>
  
  <!-- 第四格 (右下) -->
  <g transform="translate(51%,51%)">
    <rect width="48%" height="48%" fill="#FFF" stroke="#DDD"/>
    <text x="24%" y="24%" text-anchor="middle">项目 4</text>
  </g>
</svg>
```

## 📏 元素间距规范

| 关系 | 间距建议 | 说明 |
|------|---------|------|
| 主标题 ↔ 副标题 | 主标题字号 × 1.2 | 视觉关联强 |
| 标题 ↔ 正文 | 字号 × 2 | 明确章节分隔 |
| 元素 ↔ 边界 | 5-10% 画布尺寸 | 留呼吸空间 |
| 同类元素间 | 元素高度 × 0.3 | 同类聚合 |

## ⚠️ 布局陷阱

### ❌ 不要把元素紧贴边界

```xml
<!-- 推荐 -->
<text x="8%"  y="50%">左对齐</text>

<!-- 不推荐 -->
<text x="0"   y="50%">贴边</text>
```

### ❌ 不要让多个元素拥挤

```xml
<!-- 推荐：明确间距 -->
<text y="30%">标题</text>
<text y="50%">正文 1</text>
<text y="70%">正文 2</text>

<!-- 不推荐 -->
<text y="40%">标题</text>
<text y="45%">正文 1</text>  <!-- 与标题粘连 -->
```

### ❌ 不要让标题占据整个画布

保留至少 **60%** 的空间给其他元素或留白。

### ❌ 不要混用多种布局模式

一张图统一用一种布局。如果需要组合，先想清楚视觉重心。

## 🎨 响应式建议

如果同一设计要适配多种尺寸（微信/小红书/抖音），建议：

```xml
<!-- 使用 viewBox + preserveAspectRatio -->
<svg viewBox="0 0 900 383" preserveAspectRatio="xMidYMid meet">
  <!-- 内部用百分比坐标 -->
  <text x="50%" y="50%">自适应内容</text>
</svg>
```

然后按不同尺寸重新渲染，自动裁剪到目标比例。

## 📐 对齐模式

```xml
<!-- 左对齐 -->
<text x="8%" y="50%" text-anchor="start">左</text>

<!-- 居中 -->
<text x="50%" y="50%" text-anchor="middle">中</text>

<!-- 右对齐 -->
<text x="92%" y="50%" text-anchor="end">右</text>

<!-- 垂直居中 -->
<text x="50%" y="50%" dominant-baseline="middle">垂直居中</text>
```
